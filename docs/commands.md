# Команды

Дерево команд объявлено один раз в
[`crates/net/src/play/commands/registry.rs`](../crates/net/src/play/commands/registry.rs):
из него собираются пакет `commands` для клиента, подсказки tab-complete и
проверка прав. Поэтому дерево, права и выполнение не могут разойтись.

Консоль сервера подставляет фразы из `en_us.json` ванильного jar. Игроку уходит ключ перевода, клиент показывает его на своём языке. Ошибка команды игрока дополнительно пишется в лог этой фразой.

Форма узлов совпадает с ванильным `reports/commands.json` 26.3: имена
аргументов, типы парсеров и флаг `executable`. Это проверяет
[`commands_parity.rs`](../crates/net/tests/commands_parity.rs)
(`nodes_match_vanilla_shape`), иначе клиент красит рабочую команду как ошибку.

Ванильные алиасы — это `redirect` в пакете и разворот имени при разборе:
`tell`/`w` → `msg`, `tm` → `teammsg`, `tp` → `teleport`, `xp` → `experience`.
`/execute` объявлен подкомандами (`as`, `at`, `positioned`, `rotated`,
`facing`, `in`, `if`/`unless`, `align`, `anchored`, `on`, `store`, `run`) с возвратом
разбора в свой корень. `on` резолвит пассажира и транспорт, если связь уже
записана; остальные отношения отвечают «сущность не найдена». `store` пишет
в счёт и в NBT блока или сущности.

Подкоманда — всегда литерал дерева, поэтому она приходит в `Call::path`, а
не в хвосте строки. Обработчик, чей узел не исполняем (например
`/time query`), выполняет ближайшего предка с обработчиком.

Уровни прав ванильные (`reports/commands.json` версии 26.3):

| Уровень | Кто | В ваниле |
|---|---|---|
| 0 | все | — |
| 2 | гейм-мастер | `gamemasters` |
| 3 | админ | `admins` |
| 4 | владелец сервера | `owners` |

## Реализовано

| Команда | Уровень | Что делает | Отличия от ванили |
|---|---|---|---|
| `help [command]` | 0 | список доступных команд или использование | без наведения и кликабельных ссылок |
| `list [uuids]` | 0 | игроки онлайн | `uuids` печатает UUID рядом с именем |
| `tps` | 0 | строка TPS/MSPT | **расширение Chunkwake** (формат для `chunkwake-lab`) |
| `top [cpu\|tick\|mem\|world\|net]` | 2 | снимок нагрузки | **расширение Chunkwake** |
| `say <message>` | 2 | сообщение от имени сервера | — |
| `me <action>` | 0 | действие от своего имени | — |
| `msg`/`tell`/`w` | 0 | личное сообщение | нет истории и `/socialspy` |
| `teammsg`/`tm` | 0 | сообщение команде | только участникам команды отправителя; без команды — `commands.teammsg.failed` |
| `team` | 2 | команды: состав, цвет, префикс, столкновения | дружественный огонь не влияет на урон: боя команд нет |
| `tellraw` | 2 | компонент в чат | — |
| `title` | 2 | заголовок на экране | — |
| `playsound`/`stopsound` | 2 | звуки | категория (`master`…`ui`); дальше `volume * 16` звук играет у игрока с `minVolume`, `0` — ему ничего не уходит; без позиции звук у цели. `/stopsound <targets> [<source>] [<sound>]`, `*` — без категории |
| `give` | 2 | предмет в инвентарь | чары, имя, lore, `custom_data`, износ; прочие компоненты хранятся для сравнения, но не уходят клиенту |
| `clear` | 2 | очистить инвентарь | совпадают заданные компоненты; `#тег` снимает все id тега |
| `effect give\|clear` | 2 | эффекты | `infinite` и `hideParticles` |
| `xp add\|set\|query` | 2 | опыт | — |
| `gamemode`/`defaultgamemode` | 2 | режим игры | — |
| `kill` | 2 | убить | мобов и предметы тоже |
| `tp`/`teleport` | 2 | телепорт, в том числе `^` и `facing` | `^` считается от взгляда исполнителя; без углов поворот не сбрасывается |
| `damage` | 2 | урон | `fall`, `out_of_world`, `starve`, `magic`, `wither`, `arrow`; неизвестный тип — обычный урон |
| `rotate` | 2 | повернуть | — |
| `spawnpoint` | 2 | точка возрождения | пишется в сохранение игрока (`SpawnX`/`Y`/`Z`) |
| `setblock` | 2 | поставить блок | `keep` не трогает не-воздух, `destroy` дропает, `strict` падает без изменения |
| `fill` | 2 | залить область | предел 32 768; `destroy` дропает; фильтр `replace` принимает имя и `#тег` блока |
| `clone` | 2 | скопировать область | `replace`/`masked`/`filtered`, `normal`/`force`/`move`, `strict` не будит соседей; чанк должен быть уже загружен; измерение только текущее |
| `summon` | 2 | призвать моба | в мире четыре моба: корова, свинья, овца, курица |
| `weather` | 2 | погода | дождь виден, но тик осадков не считается |
| `gamerule` | 2 | правила мира | 59 правил 26.3; тик читает часть |
| `time set\|add\|query` | 2 | время | `query` — `time` и `gametime`, как в 26.3 (`daytime` ещё принимается) |
| `difficulty` | 2 | сложность | — |
| `seed` | 2 | зерно мира | — |
| `version` | 2 | версия сервера | — |
| `setworldspawn` | 2 | точка появления мира | — || `worldborder` | 2 | граница мира | центр, диаметр, предупреждение и урон хранятся и уходят клиенту; урон игроку на кромке пока не считается |
| `forceload` | 2 | чанк остаётся в симуляции | очередь подгрузки с диска отдельно не ведётся |
| `locate biome\|poi\|structure` | 2 | биом по климату; структура по сиду; точка интереса по блокам загруженных чанков | биом: радиус 4096, шаг 32, высота в ответе — поверхность столбца. Структура: деревни, аванпосты, заброшенные лагеря, пустынные пирамиды, джунглевые храмы, хижины, иглу, кораблекрушения, шахты, океанский монумент и крепость; остальные id — «не найдено». `poi` чанки не создаёт, радиус 256 |
| `scoreboard objectives` | 2 | цели счёта | `modify` — `displayname`, `rendertype` и `numberformat` (`blank`, `fixed`, `styled`; голое слово сбрасывает формат). Формат цели уходит в `set_objective` |
| `scoreboard players` | 2 | значения счёта | `display numberformat` хранится на счёте и в `set_score` не пишется; `enable` открывает цель `trigger` |
| `data get\|merge\|modify` | 2 | NBT блока и сущности | путь `Foo.Bar[0]`, `merge`, `modify set\|merge\|append\|prepend\|insert` |
| `execute … run <command>` | 2 | цепочка контекстов | `align`, `anchored`, `on`, `store` в счёт и в NBT блока или сущности; `summon` ставит сущность и продолжает от её имени; `if`/`unless` — `biome`, `blocks`, `data`, `loaded`, `items`, `slots`, `score matches`; `positioned over` ставит Y по карте высот |
| `tag` | 2 | метки сущностей | до 1024 меток; селектор `tag=` их видит |
| `swing` | 2 | взмах руки | `mainhand`/`offhand`, анимации `none`/`whack`/`stab`; предмет и снаряд — `notliving` |
| `spectate` | 2 | камера наблюдателя | только режим spectator; пакет `set_camera` |
| `ride` | 2 | посадить и снять | пассажир не садится на игрока и не замыкает круг; клиенту уходит `set_passengers` |
| `trigger` | 0 | свой trigger-счёт | работает после `scoreboard players enable`; повтор без enable — `unprimed` |
| `random` | 0 | случайное число | `roll` пишет в чат, `value` возвращает число; последовательность помнит семя, пока сервер запущен. Генератор не совпадает побитово с ванильным `RandomSequence` |
| `bossbar` | 2 | полоска босса | зрители задаются `set players`; при входе и возрождении полоска приходит снова. Небо, музыка и туман не включаются |
| `enchant` | 2 | чары на предмет в руке | уровень `0` снимает чары; несовместимые не заменяются; книга пишет `stored_enchantments` |
| `spreadplayers` | 2 | разбросать сущности | высота — поверхность `motion_blocking` уже загруженного чанка; `under` не ищет пещеры ниже этой поверхности |
| `stopwatch` | 2 | секундомер | считает реальное время, не тики; `query` для `execute store` отдаёт `floor(секунды × scale)` |
| `posteffect` | 2 | эффект экрана | игроку уходит полный список `post_effects` |
| `attribute` | 2 | база и модификаторы атрибута | игрок — набор игрока, моб — набор моба; пакет `update_attributes`. Спринт сессии в `get` не входит |
| `fillbiome` | 2 | биом в коробке | чанки должны быть загружены; клиенту уходит `chunks_biomes`; объём ограничен `max_block_modifications` |
| `waypoint` | 2 | цвет и стиль путевой точки | точка есть у игрока; моб и предмет — `argument.waypoint.invalid`. Команда точку не создаёт. Клиенту уходит `waypoint` |
| `dialog` | 2 | закрыть диалог | `clear` шлёт пустой `clear_dialog`. `show` отвечает «не найден»: реестра диалогов нет |
| `particle` | 2 | частицы у игроков рядом | простые типы (`flame`, `heart`, …) уходят `level_particles`. `dust`, `block`, `item` и прочие с телом пакета — `particle.invalidOptions`. Дальше 32 блоков нужна `force` (до 512) |
| `return` | 2 | выход из функции | функций нет: любая форма отвечает, что команда работает только внутри функции |
| `item` | 2 | предмет в слот | только `replace entity <targets> <slots> with <item> [count]`. Слоты: `weapon`, `weapon.mainhand`, `weapon.offhand`, `weapon.*`, `armor.head`…`armor.feet`, `armor.*`, `hotbar.N`, `inventory.N`, `container.N`. У моба слотов нет — `commands.item.target.no_such_slot`. Ветки `block`, `from`, `modify`, `fill`, `override` в дереве не объявлены |
| `loot` | 2 | выдать или выбросить по таблице | `give players … loot`, `spawn <pos> loot`, `insert <pos> loot`, `replace block <pos> <slot> [count] loot`. Ключ таблицы — путь от `loot_table` (`minecraft:blocks/stone`, `minecraft:chests/abandoned_mineshaft`). `kill`, `fish`, `mine` отвечают, что нужен источник урона или удочка. `replace entity` не объявлен |
| `place` | 2 | постройка из шаблона | только `template <id> <pos> [rotation] [mirror]`. Шаблоны берутся из `data/minecraft/structure`: `minecraft:desert_well/well`, `minecraft:igloo/bottom`. Блоки ставятся как `setblock replace`, блочные сущности (сундук, табличка) не заполняются. `integrity` и `seed` отвечают, что процессоров нет. `feature`, `jigsaw`, `structure` не объявлены |
| `op`/`deop` | 3 | права оператора | `ops.json` ванилы |
| `kick` | 3 | выгнать | причина попадает в ответ |
| `whitelist` | 3 | белый список | включённый список проверяется при входе; оператор проходит |
| `ban`/`ban-ip`/`banlist`/`pardon`/`pardon-ip` | 3 | баны | имя и IP проверяются при входе |
| `reload` | 2 | перечитать `ops.json` | датапаков нет |
| `tick` | 3 | `query`, `rate`, `freeze`, `step`, `sprint` | `sprint` ускоряет цикл |
| `debug start\|stop` | 3 | профиль тика в `debug/profile-*.txt` | запись MSPT по тикам, не `spark` |
| `perf start\|stop` | 4 | снимок нагрузки и профиль | — |
| `stop` | 4 | сохранить мир и выйти | — |
| `save-all`/`save-off`/`save-on` | 4 | автосейв | `save-all` просит автосейв вне расписания |
| `publish`/`unpublish` | 4 | LAN-публикация | только флаг, UPnP не трогаем |
| `transfer` | 3 | переслать на другой сервер | клиенту уходит пакет `transfer`, затем сессия закрывается |
| `setidletimeout` | 3 | таймаут простоя | нет игровых пакетов дольше N минут — сессия закрывается; 0 выключает таймаут |

## Чего пока нет

Перечислено явно: тест
[`commands_parity.rs`](../crates/net/tests/commands_parity.rs) сверяет дерево с
ванильным 26.3 и падает, если список ниже разойдётся с кодом.

`advancement`, `compute`, `datapack`,
`fetchprofile`, `function`, `jfr`,
`recipe`,
`schedule`, `test`.

Часть из них требует подсистем, которых ещё нет: scoreboard в тике, загрузчик
датапаков, генератор структур, рецепты для игрока.

## Селекторы

Поддерживаются `@s`, `@p`, `@r`, `@a`, `@e` и имя игрока с аргументами:

```
@a[distance=..20,gamemode=creative]
@e[type=minecraft:cow,limit=5,sort=nearest,tag=farm]
@p[x=0,y=64,z=0,dx=10,dy=10,dz=10]
@a[name=Ali*,level=1..]
```

Разбираются `sort`, `limit`, `distance`, `dx`/`dy`/`dz`, `gamemode`, `name`,
`tag`, `scores`, `rot`; `type=` отличает моба от игрока.

## Подсказки

Литералы и аргументы клиент подсказывает сам по пакету `commands`. На
`command_suggestion` сервер отвечает тем, что клиент знать не может: имена
команд плагинов и то, что пришло от плагинов (`TabComplete`). Список
дополняется, а не заменяется: пустой ответ не затирает дерево.

## Консоль

Те же команды, что и в чате, без `/`: `chunkwake` читает `stdin` построчно.
`stop` завершает сервер, `top` печатает снимок нагрузки в лог.
