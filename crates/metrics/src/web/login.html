Chunkwake — вход

Введите токен метрик, чтобы открыть панель состояния сервера.

Неверный токен. Проверьте metrics-token в server.properties.
Токен задаётся в конфигурации: chunkwake config set metrics-token <значение>. Если панель нужна только с этой машины, оставьте metrics-bind на loopback: metrics-bind=127.0.0.1.
