Этот дашборд открыт из сети, поэтому нужен токен из настроек сервера.

Токен не подошёл. Проверьте metrics-token в server.properties.
Токен задаётся на сервере: chunkwake config set metrics-token <значение>. Чтобы открывать дашборд только с этой машины, привяжите его к loopback: metrics-bind=127.0.0.1.
